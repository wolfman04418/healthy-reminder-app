# HealthyReminder 👁️

A desktop eye health reminder application based on the **20-20-20 rule**.

The application helps users reduce digital eye strain by reminding them to take regular breaks while using computers.

## Features

- ⏰ Automatic break reminders
- 👀 20-20-20 eye care method
- 🖥️ Windows desktop application
- ⚙️ Simple and lightweight interface

## Technology Stack

- C#
- .NET
- WPF (Windows Presentation Foundation)
- XAML

## How It Works

Every 20 minutes:

1. The application reminds the user
2. The user looks at something 20 feet away
3. The user rests their eyes for 20 seconds
